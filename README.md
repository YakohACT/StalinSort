# スターリンソートとは
スターリンソート最大の特徴は
<br> __for文が1個だけでいい__
<br> なのでO(n)ととても効率的
<br> やり方もとても簡単
<br> 前より小さいやつは __粛清__ ~~それソートじゃない~~
<br> 他のソートと比べてもとても合理的です！！
